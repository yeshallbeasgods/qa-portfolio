# Four smaller repos

These are smaller demonstration repos. Each shows one tool at a small scale, and their READMEs are brief. I describe them here only as far as the repositories themselves do.

- **[Playwright + Java](https://github.com/yeshallbeasgods/refined-joyous-camellia):** Playwright automation written in Java against a demo shop and a weather API.
- **[Cypress + TypeScript](https://github.com/yeshallbeasgods/indiscreet-pocketed-orange):** a lean component-testing repo with API mocking and no page objects.
- **[Appium + Python](https://github.com/yeshallbeasgods/rising-oceans-phoenix):** a simple repo showing native mobile testing.
- **[Python API + performance](https://github.com/yeshallbeasgods/graceful-bluesilver-waltz):** a full API suite using Locust, pytest and requests, with SQLite and basic mock services.

To see which of these are publishing live results, check the [dashboard](https://yeshallbeasgods.github.io/).
